# SMARTBIO Website

A polished one-page website for Renuka Bansal's SMARTBIO GCSE and A Level Biology tutoring.

## Preview

Open `index.html` directly in a browser, or run a local static server from this folder:

```powershell
python -m http.server 8010 --bind 127.0.0.1
```

Then visit:

```text
http://127.0.0.1:8010/index.html
```

## Before publishing

Update the enquiry form recipient in `script.js`:

```js
const contactEmail = "renuka.bansal@example.com";
```

Replace it with Renuka's preferred contact email address.
